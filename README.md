# AI Sentiment Analysis Web App

## Mô tả
Ứng dụng web sử dụng AI đơn giản để phân tích cảm xúc phản hồi khách hàng.

## Chức năng
- Phân tích cảm xúc phản hồi
- Kết quả: Tích cực / Tiêu cực / Trung lập
- Giao diện web đơn giản

## Công nghệ sử dụng
- HTML
- CSS
- JavaScript
- Docker
- Vercel
